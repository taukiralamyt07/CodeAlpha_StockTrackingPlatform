# CodeAlpha Stock Trading Platform

A console-based Java stock trading simulation demonstrating OOP, collections, buy/sell operations, portfolio performance, and file persistence.

## Features
- Market data display
- Buy and sell operations
- ₹100,000 starting virtual cash
- Holdings and average buy price tracking
- Portfolio value and profit/loss calculation
- Add/update stocks
- Portfolio persistence using Java serialization (`portfolio.dat`)

## Run
```bash
javac src/Main.java
java -cp src Main
```
